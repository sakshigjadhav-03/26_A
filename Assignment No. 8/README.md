
# Assignment 8: Student Records REST API

## Aim
To develop a REST API using Node.js, Express.js and MongoDB.

## Technologies
- Node.js
- Express.js
- MongoDB
- Mongoose
- Thunder Client

## API Endpoints
- POST /api/students - Create a student
- GET /api/students - View all students
- GET /api/students/:id - View one student
- PUT /api/students/:id - Update a student
- DELETE /api/students/:id - Delete a student

## Run the Project
1. Run npm install.
2. Create a .env file with PORT and MONGO_URI.
3. Start MongoDB.
4. Run npm run dev.
5. Test the endpoints using Thunder Client.
